# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Yash uses the Quartz knowledge base and its underlying Obsidian vault to find notes and navigate daily work.

## Product Purpose

Make capture, knowledge retrieval, and navigation easy with minimal repeated reading and AI token use.

## Operating Context

An existing Quartz website publishes selected knowledge, projects, and resources. Obsidian contains the complete local vault. The user requested a dashboard in both environments.

## Capabilities and Constraints

Preserve local source captures and their provenance. Private inboxes, journals, trackers, areas, and exports remain excluded from the website. Work locally; deployment is outside this change. Use existing Quartz search and generated topic indexes. The private Home must work without installing a plugin.

## Product Principles

- Put search and common destinations first.
- Show real notes and counts, not invented progress.
- Generate navigation from existing metadata rather than repeated AI synthesis.
- Keep personal operations private.

## Brand Commitments

The user requested the portfolio screenshot’s charcoal, warm ivory, yellow, and teal color scheme for the website. Preserve legible reading contrast in both themes.
